\section{Introduction}
\label{sec:intro}

\subsection{Motivation}
Urban intersection safety critically depends on visibility between pedestrians and approaching vehicles. At crosswalks, pedestrians often face blocked views due to parked cars, infrastructure, or other vehicles, creating serious safety risks. In the United States, 7,388 pedestrians were killed in traffic crashes in 2021, with limited sight distance cited as a contributing factor~\cite{nhtsa2023pedestrian}. Traditional line-of-sight (LoS) audits rely on manual 2D analysis or simple geometric rules that cannot capture complex 3D occlusions from dynamic objects and multi-view perspectives.

\subsection{Our Approach}
We present a two-pass 3D reconstruction system that processes synchronized multi-camera video to create time-consistent scenes with both static geometry and tracked dynamic objects for automated LoS visibility audits. 

\textbf{\green{Pass 1 - Static Reconstruction:}} \green{We reconstruct the static scene using DUSt3R~\cite{dust3r} to establish a shared world coordinate system and dense point cloud from 8 synchronized cameras at a 4-corner intersection.}

\textbf{Pass 2 - Dynamic Tracking:} \green{We track dynamic objects (pedestrians and vehicles) using YOLOv8x~\cite{yolov8} for detection and} \red{ByteTrack~\cite{bytetrack} for multi-object tracking.} \green{We perform per-camera tracking, classify objects as stationary vs. moving, and project 2D detections to 3D using camera parameters and ground plane fitting, creating 3D trails for each tracked object.} \red{Multi-camera association will merge tracks across views using spatial proximity and temporal overlap. Each global object will be represented as a canonical 3D primitive: motion-oriented bounding boxes for vehicles, vertical cylinders for pedestrians.}

\textbf{\red{Pass 3 - LoS Audit:}} \red{We will cast rays from pedestrian eye points to vehicles through the combined static + dynamic scene to determine visibility timing and identify occluders.}

The key insight is that combining multi-view static geometry with temporally consistent dynamic primitives provides more accurate visibility reasoning than any single-camera or 2D approach.
