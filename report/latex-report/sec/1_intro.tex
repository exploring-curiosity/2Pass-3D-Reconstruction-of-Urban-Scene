\section{Introduction}
\label{sec:intro}

Urban intersection safety critically depends on visibility between pedestrians and approaching vehicles. At crosswalks, pedestrians often face obstructed views due to parked cars, infrastructure elements, or other vehicles, creating serious safety hazards. In the United States, 7,388 pedestrians were killed in traffic crashes in 2021, with limited sight distance cited as a contributing factor in many cases~\cite{nhtsa2023pedestrian}. Traditional line-of-sight (LoS) audits rely on manual 2D analysis or simplified geometric rules that cannot capture the complex 3D occlusions arising from dynamic objects and multi-view perspectives.

\subsection{Motivation}

Existing approaches to intersection visibility analysis suffer from fundamental limitations:

\begin{itemize}
    \item \textbf{Manual audits} are time-consuming, subjective, and cannot capture temporal dynamics of moving traffic
    \item \textbf{2D video analysis} cannot reason about 3D occlusions or depth relationships between objects
    \item \textbf{Single-camera methods} have limited field of view and suffer from occlusion blind spots
    \item \textbf{Static-only reconstruction} ignores the critical role of dynamic objects (moving vehicles, pedestrians) in creating visibility hazards
\end{itemize}

These limitations motivate our approach: a multi-camera 3D reconstruction system that captures both static scene geometry and dynamic object trajectories for comprehensive visibility analysis.

\subsection{Our Approach}

We present a two-pass pipeline that processes synchronized multi-camera video to create time-consistent 3D scenes with both static geometry and tracked dynamic objects:

\textbf{Pass 1: Static Scene Reconstruction.} We extract static background images via temporal median filtering and employ Pi3~\cite{pi3} for multi-view geometry estimation. Pi3 jointly optimizes camera poses and produces a dense global point cloud in a shared world frame. We apply SegFormer~\cite{segformer} semantic segmentation to identify road and sidewalk regions for robust RANSAC ground plane fitting.

\textbf{Pass 2: Dynamic Object Tracking.} We detect objects using YOLOv8x~\cite{yolov8} and track them with ByteTrack~\cite{bytetrack} independently per camera. We project 2D detections to 3D world coordinates using camera parameters from Pass 1 and the estimated ground plane. Multi-camera track association merges observations across views, and each object is represented as a canonical 3D primitive: oriented bounding boxes for vehicles, vertical cylinders for pedestrians.

\subsection{Contributions}

Our main contributions are:

\begin{enumerate}
    \item A complete two-pass pipeline for multi-camera 3D reconstruction of urban intersections, combining static scene geometry with dynamic object tracking
    
    \item Integration of state-of-the-art components: Pi3 for uncalibrated multi-view reconstruction, YOLOv8x + ByteTrack for detection and tracking, and SegFormer for semantic segmentation
    
    \item Multi-camera track association using spatial-temporal clustering to maintain consistent object identities across views
    
    \item Canonical 3D primitive representation (oriented bounding boxes, cylinders) enabling efficient ray-geometry intersection for visibility analysis
    
    \item Comprehensive evaluation on a real urban intersection dataset with 8 synchronized cameras, demonstrating accurate reconstruction and tracking performance
\end{enumerate}

The key insight is that combining multi-view static geometry with temporally consistent dynamic primitives provides the foundation for accurate visibility reasoning that single-camera or 2D approaches cannot achieve.
