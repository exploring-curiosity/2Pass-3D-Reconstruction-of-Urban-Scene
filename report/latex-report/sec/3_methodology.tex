\section{\blue{Method}}
\label{sec:method}

\blue{Our system processes multi-camera synchronized video from a 4-corner intersection to reconstruct static and dynamic 3D scene elements for Line-of-Sight visibility analysis.}

\subsection{\blue{Pass 1: Static Scene Reconstruction}}
\blue{We extract static background images per camera via temporal median filtering ($B(x,y) = \text{median}_t(I_t(x,y))$ over 300 frames) and apply Pi3~\cite{pi3} for multi-view geometry estimation. Pi3 jointly optimizes camera poses and produces a dense global point cloud ($\sim$1.2M points) in a shared world frame with camera intrinsics $K_i$ and extrinsics (camera-to-world poses $T_{c2w}$). For ground plane estimation, we apply SegFormer~\cite{segformer} semantic segmentation to identify road/sidewalk regions, then use RANSAC plane fitting. Metric scale is recovered using known crosswalk stripe widths (0.3m).}

\subsection{\blue{Pass 2: Dynamic Object Tracking}}

\subsubsection{\blue{Detection and Per-Camera Tracking}}
\blue{We apply YOLOv8x~\cite{yolov8} for object detection (person, car, truck, bus, bicycle) and ByteTrack~\cite{bytetrack} for per-camera multi-object tracking. ByteTrack associates both high and low-confidence detections, improving tracking through occlusions.}

\subsubsection{\blue{Stereo Triangulation for 3D Localization}}
\blue{Each corner has a stereo pair (left/right cameras). For matched detections across the pair, we triangulate 3D positions using:}
\begin{equation}
\blue{\mathbf{X} = \text{triangulate}(P_L, P_R, \mathbf{u}_L, \mathbf{u}_R)}
\end{equation}
\blue{where $P = K[R|t]$ are projection matrices from Pi3 camera parameters. For single-camera detections, we project to the ground plane ($z=0$) by ray-plane intersection.}

\subsubsection{\blue{Kalman Filter Tracking}}
\blue{Each 3D track maintains a Kalman filter with 6-state (position + velocity). The filter predicts positions between frames and updates with triangulated measurements, providing smooth trajectories and handling temporary occlusions.}

\subsubsection{\blue{Multi-Camera Association}}
\blue{Tracks from different stereo pairs are merged using spatial-temporal clustering: (1) same object category, (2) 3D proximity $<$2.0m for vehicles, $<$1.0m for pedestrians, (3) temporal overlap $\geq$30\%. Union-find clustering produces global object IDs.}

\subsubsection{\blue{Canonical Primitive Representation}}
\blue{Each object is represented as a 3D primitive: oriented bounding boxes for vehicles with class-specific dimensions (car: 4.5$\times$1.8$\times$1.5m, truck: 7.0$\times$2.5$\times$3.0m), and vertical cylinders for pedestrians (r=0.25m, h=1.7m). Objects are classified as static or moving based on trajectory variance ($\sigma < 0.5$m).}

\subsection{Pass 3: Line-of-Sight Audit}
For visibility analysis, we implement a ray-casting pipeline that determines precisely when an approaching vehicle becomes visible to a pedestrian. To handle the complexity of dense point clouds and arbitrary metric scales, we employ spatial voxelization and biological scale calibration.

\subsubsection{Scale Calibration and Spatial Indexing}
Since Pi3 outputs geometry in arbitrary units, we recover metric scale using a biological prior. We calculate the median height of high-confidence pedestrian tracks in the unscaled space and compute a scale factor $S$ to anchor this median to 1.7m (average human height). This aligns the entire scene to real-world dimensions without relying on potentially degraded road markings.

To make ray-casting computationally feasible against a dense point cloud (15k points/m$^2$), we downsample the static scene into a Voxel Grid (20cm leaf size). This creates a lightweight occupancy map that preserves major occluders (poles, parked trucks) while significantly accelerating intersection testing.

\subsubsection{Visibility Scoring}
We define visibility not as a binary state, but as a confidence score. For each pedestrian-vehicle pair:
\begin{enumerate}
    \item \textbf{Ray Bundle Casting:} We cast rays from the pedestrian's eye point (1.6m height) to $K=5$ keypoints on the vehicle (bumper center, headlights, hood, roof).
    \item \textbf{Visibility Score ($V_t$):} A vehicle is classified as \textit{Visible} only if $>60\%$ of rays reach the target without intersecting occupied voxels or other dynamic primitives.
    \item \textbf{Occluder Identification:} For each blocked ray, we identify whether the occlusion is caused by static infrastructure (poles, signs), parked vehicles, or moving vehicles, enabling targeted safety recommendations.
\end{enumerate}
