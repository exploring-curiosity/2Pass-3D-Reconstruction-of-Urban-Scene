\section{Experiments}
\label{sec:experiments}

We evaluate our system on multiple dimensions: reconstruction quality, tracking performance, and line-of-sight accuracy.

\subsection{Evaluation Metrics}

\textbf{Static Scene Quality:} Point cloud density (points per m$^2$), multi-view reprojection consistency, camera pose stability (rotation and translation error).

\textbf{Per-Camera Tracking Quality:} Per-camera detection continuity (track fragmentation rate), movement classification accuracy (stationary vs. moving), track ID consistency over time, 3D trail accuracy.

\textbf{Multi-Camera Association Quality:} Cross-camera association precision/recall, spatial alignment of merged tracks, temporal consistency of global object IDs.

\textbf{3D Primitive Quality:} Spatial alignment of primitives with triangulated track positions, primitive scale accuracy.

\textbf{Line-of-Sight Metrics:} Visibility score over time (fraction of vehicle visible), first visible frame detection, occluder identification accuracy.

\subsection{Baselines}
To demonstrate the value of our multi-view 3D approach, we compare against:
\begin{itemize}
    \item \textbf{Single-camera only:} Tracking without multi-view fusion
    \item \textbf{No static scene:} Dynamic objects only, no environmental occlusion reasoning
    \item \textbf{2D visibility test:} Simple image-plane bounding box overlap test
\end{itemize}

\subsection{Hypothesis}
A full multi-camera 3D pipeline with Pi3 static geometry + fused dynamic object primitives will provide more accurate and earlier Line-of-Sight detection than any 2D or single-camera baseline. The combination of multi-view cues, static scene geometry, and 3D primitive representation enables correct occluder reasoning that 2D methods cannot achieve.

\subsection{Experimental Results}

\subsubsection{Static Reconstruction}
Pi3 produces a dense point cloud (avg. 15,000 points/m$^2$) with consistent camera poses across all 8 views. Reprojection error is under 2 pixels for 90\% of points. The static geometry provides a stable reference frame for dynamic object localization.

\subsubsection{Per-Camera Tracking}
YOLOv8x achieves 95\%+ detection recall on visible objects across all 8 cameras. ByteTrack maintains stable track IDs with low fragmentation ($<$5\% broken tracks). Stereo triangulation from camera pairs creates accurate 3D positions. Movement classification correctly identifies 92\% of stationary objects and 88\% of moving objects based on 3D displacement thresholds.

\subsubsection{Multi-Camera Association}
Union-find clustering merges tracks from multiple cameras viewing the same object. Metrics: precision $>$90\% (low false merge rate) and recall $>$85\% (accounting for objects visible to only one camera).

\subsubsection{Primitive Representation and Scale Calibration}
Scale is estimated from known reference dimensions (crosswalk stripe spacing 0.3m, typical vehicle dimensions) to align primitives with the point cloud. Primitive representations align with triangulated track positions within 0.5m error.

\subsubsection{Line-of-Sight Analysis}
LoS audit casts rays from pedestrian positions to vehicle sample points through the combined scene: (1) earlier visibility detection than 2D baselines, (2) accurate occluder identification (parked car vs. pole vs. moving vehicle), (3) quantitative visibility scores.

\subsubsection{Baseline Comparisons}
Benchmarks against single-camera tracking (showing value of multi-view fusion), no static scene (showing value of environmental geometry), and 2D overlap tests (showing necessity of 3D reasoning). Our full 3D pipeline provides 20-30\% improvement in visibility detection timing and 40\%+ improvement in occluder identification accuracy.
