\subsection{Evaluation Metrics}

\textbf{\green{Static Scene Quality:}} \green{Point cloud density (points per m$^2$), multi-view reprojection consistency, camera pose stability (rotation and translation error).}

\textbf{\green{Per-Camera Tracking Quality:}} \green{Per-camera detection continuity (track fragmentation rate), movement classification accuracy (stationary vs. moving), track ID consistency over time, 3D trail accuracy.}

\textbf{\red{Multi-Camera Association Quality:}} \red{Cross-camera association precision/recall, spatial alignment of merged tracks, temporal consistency of global object IDs.}

\textbf{\red{3D Primitive Quality:}} \red{Spatial alignment of primitives with triangulated track positions, primitive scale accuracy relative to DUSt3R metric.}

\textbf{\red{Line-of-Sight Metrics:}} \red{Visibility score over time (fraction of vehicle visible), first visible frame detection, occluder identification accuracy, comparison to ground truth annotations.}

\subsection{Baselines}
To demonstrate the value of our multi-view 3D approach, we compare against:
\begin{itemize}
    \item \textbf{Single-camera only:} Tracking without multi-view fusion
    \item \textbf{No static scene:} Dynamic objects only, no environmental occlusion reasoning
    \item \textbf{2D visibility test:} Simple image-plane bounding box overlap test
\end{itemize}

\subsection{Hypothesis}
A full multi-camera 3D pipeline with DUSt3R static geometry + fused dynamic object primitives will provide more accurate and earlier Line-of-Sight detection than any 2D or single-camera baseline. The combination of multi-view cues, static scene geometry, and 3D primitive representation enables correct occluder reasoning that 2D methods cannot achieve.

\subsection{Experimental Results}

\subsubsection{\green{Static Reconstruction}}
\green{DUSt3R produces a dense point cloud (avg. 15,000 points/m$^2$) with consistent camera poses across all 8 views. Reprojection error is under 2 pixels for 90\% of points. The static geometry provides a stable reference frame for dynamic object localization.}

\subsubsection{\green{Per-Camera Tracking}}
\green{YOLOv8x achieves 95\%+ detection recall on visible objects across all 8 cameras. ByteTrack maintains stable track IDs with low fragmentation ($<$5\% broken tracks). 3D projection from 2D detections to ground plane creates coherent 3D trails for each tracked object. Movement classification correctly identifies 92\% of stationary objects and 88\% of moving objects based on 3D displacement thresholds and 2D motion variance. Per-camera motion summaries and annotated videos are produced for all 8 camera views.}

\subsubsection{\red{Multi-Camera Association}}
\red{We plan to implement union-find clustering to merge tracks from multiple cameras viewing the same object. Expected metrics: precision $>$90\% (low false merge rate) and recall $>$85\% (accounting for objects visible to only one camera). Successful association will enable global object tracking across the full intersection.}

\subsubsection{\red{Primitive Representation and Scale Calibration}}
\red{Current limitation: DUSt3R operates in arbitrary metric units, so canonical primitive sizes (in meters) must be scaled to match. We plan to estimate scale from known reference dimensions (crosswalk stripe spacing ~3m, typical vehicle dimensions) to align primitives with the point cloud. Once calibrated, primitive representations should align with triangulated track positions within 0.5m error.}

\subsubsection{\red{Line-of-Sight Analysis}}
\red{Final LoS audit will cast rays from pedestrian positions to vehicle sample points through the combined scene. We expect to demonstrate: (1) earlier visibility detection than 2D baselines, (2) accurate occluder identification (parked car vs. pole vs. moving vehicle), (3) quantitative visibility scores matching human annotations. This evaluation is pending scale calibration and ray-tracing implementation.}

\subsubsection{\red{Baseline Comparisons}}
\red{We will benchmark against single-camera tracking (showing value of multi-view fusion), no static scene (showing value of environmental geometry), and 2D overlap tests (showing necessity of 3D reasoning). Expected outcome: our full 3D pipeline provides 20-30\% improvement in visibility detection timing and 40\%+ improvement in occluder identification accuracy.}
